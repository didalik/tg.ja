Toll-Gated Job session: echo

This page is a live Job Requester (jr), running entirely in your browser: it places one real Stellar trade for the whole session, gets matched with whichever Agent sells this echo cheapest right now over WebSocket, then lets you chat with it -- as many messages as you like, all on that one trade -- and submits the Proof of Delivery once you end the session.

Type a plain message and it echoes it back exactly. Type real arithmetic instead (e.g. 17*23, not "what's 17 times 23?" -- only the first looks enough like arithmetic to act on) and watch for a reply that's just the number, 391: a plain heuristic recognized the input, paid a separate Job (calc, in real crypto, over this same Toll Gate -- opens in its own tab) for the exact answer, and relayed it back. If you're matched against the real Owner, this is deterministic every time; if a demo visitor's own transient identity happens to be cheaper right now, it's that same mechanism running on their own self-issued or resold inventory instead -- either way, the page tells you which once you're matched.
