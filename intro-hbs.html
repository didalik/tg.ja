Dear Reader,

Welcome to the Kloud Of Trust - the cloud-native, role-based organization of coders and testers. At present, it is my hobby project with three more projects in it:

  • Stellar TESTNET Monitor (TM),
  • Cloudflare Job Fair (jF), and
  • Stellar Help Exchange (hX).

The TM is a Stellar DEX-based semaphore to gate and queue jF Job Requests. When a Job Request is granted, TM starts the corresponding Job Agent. This serverless solution enables a 24/7 listener behind my ISP. See k2.hx GitHub repo for details.

The jF matches Job Agents (digital content producers) with Job Users (digital content consumers) for a given Job and facilitates the data flow between them. I employ Hibernation WebSocket API to implement a Match → Relay handshake that pairs up two sockets (a Job Offer from the Job Agent and a Job Request from the Job User) and then relays messages between the paired. The SDK is on GitHub.

The hX provides an equitable marketplace, where job users pay job agents for jobs done - or get full refund otherwise. My k2.hx GitHub repo has more details - sequence diagrams, API and SDK. There is also a small demo based on this YouTube video. Combined, it is a TM/jF/hX integration test. I believe these are small but necessary steps to make the Internet a better place for you and me. So, if you are a coder, consider joining me on GitHub. As a tester, get paid for running my demo!

Summing up, the TM/jF/hX solution gives developers like me real collaboration power and, for example, scales well into the realms of Agentic AI. Join me, won't you?
