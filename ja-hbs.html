FOR DEVS AND TESTERS ONLY

This page is a browser-based Job Requester (jr) for the Toll Gate's ja Job Agent -- a live test of the same wiring tg/ja/public/jr/run.js already proves from Node:
  • discover the Agent's Stellar issuer PK from ja's own job registry;
  • place the matching Stellar DEX trade to open the toll gate;
  • connect over WebSocket, get matched with the Agent, and run the echo job.

See k2's tg/ directory and daeh for the code.
